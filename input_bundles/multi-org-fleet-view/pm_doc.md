# Multi-Org Fleet View: Monitor Every Fleet from a Single Workspace

Operators managing drone operations across multiple FlytBase
organizations often keep several Fleet View tabs open at the same
time---one for each customer. Monitoring fleet status means constantly
switching between tabs, making it difficult to maintain situational
awareness across the entire operation.

Multi-Org Fleet View brings every organization into a single workspace.
Drones, sites, alarms, telemetry, and live video feeds from multiple
organizations are available together, allowing operators to monitor
their complete fleet without changing tabs.

This Flex App is designed for service providers, managed operations
teams, and enterprises that operate drones across multiple customer
organizations.

> **Note:** Multi-Org Fleet View is available as a Flex App and is not
> part of the standard FlytBase Operations Dashboard.

## Accessing Multi-Org Fleet View

Multi-Org Fleet View can be launched from any FlytBase organization that
you are a member of.

To access it:

1.  Navigate to **Operations Dashboard**.
2.  Open the **Hamburger Menu** in the upper-left corner.
3.  Select **Flex Factory**.
4.  Open **Multi-Org Fleet View**.

The application aggregates fleet data from every organization that your
user account has permission to access. You can launch the app from any
organization that you are a member of.

> **Info**
>
> Multi-Org Fleet View only displays organizations that your FlytBase
> user account has permission to access. If an organization is not
> visible, verify that your account has access to that organization.

## What's in Multi-Org Fleet View

### Organization Selector

Select one or more FlytBase organizations to include in the current
view. Fleet data from every selected organization is aggregated into a
single workspace.

Organizations can be added or removed at any time without leaving the
application.

### Unified Fleet Map

The map displays drones from every selected organization simultaneously.

Operators can monitor aircraft position, flight status, telemetry, and
site location across all organizations from a single map without
switching browser tabs.

### Fleet Table

The Fleet Table combines drones from every selected organization into a
single list.

Each row displays the organization, site, device status, battery,
connectivity, and operational telemetry, making it easy to identify
devices that require attention.

Search and filtering work across the combined fleet.

### Unified Alarm Monitoring

Alarms from every selected organization appear together in a single
alarm panel.

Operators can quickly identify which organization generated the alarm,
review its severity, and investigate the affected device without
changing workspaces.

### Live Video

Live video feeds can be opened directly from any drone, regardless of
which organization owns it.

Operators can continue monitoring the complete fleet while viewing live
video from an individual drone.

------------------------------------------------------------------------

## Current Scope

The current release focuses on cross-organization fleet visibility.

Operators can:

-   Monitor drones across multiple organizations
-   View fleet telemetry
-   Monitor alarms
-   Open live video feeds
-   Search and filter the combined fleet

Mission execution workflows---including **Go To Location**, **Mission
Launch**, and **bulk flight operations**---have been developed but are
not included in the current release.
