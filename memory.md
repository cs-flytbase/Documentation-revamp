# Memory Index

Pointer file for the drafting agent. Lists all memory files and what they cover.
Correction files are populated by the memory updater through reviewer feedback.
Feature notes are auto-generated by the pipeline on each run.

## Corrections
- [voice_corrections.md](memory/voice_corrections.md) — Tone, language, and word choice rules learned from reviewer feedback
- [placement_corrections.md](memory/placement_corrections.md) — IA placement rules learned when reviewers moved pages to different sections
- [formatting_corrections.md](memory/formatting_corrections.md) — Structure and layout rules learned from reviewer edits
- [terminology.md](memory/terminology.md) — Product name spellings, capitalization, and acronym rules

## Feature Notes (auto-generated)
Feature context files live in `memory/features/`. Each is auto-generated when the pipeline
processes a new feature — contains key concepts, IA placement, related pages, and specs.
The drafting agent reads relevant feature notes to maintain cross-feature consistency.
